# No AI Slop

No AI Slop is a skills-only ChatGPT and Codex Plugin for removing recurring AI-style writing patterns without flattening the writer's voice.

The Plugin is built as a connected set of specialist Skills for slop auditing, voice-preserving editing, natural spoken writing, Arabic and Egyptian Arabic style, truthful commercial copy, presentation and visual-content review, targeted pattern repair, strict output rules, and final quality checks.

It does not require an external server, account, authentication flow, or publisher-hosted data store.

## Canonical ID & Marketplace Namespace Advisory

In response to upstream marketplace reports regarding canonical ID collisions (`no-ai-slop@openai-curated-remote` alongside third-party packages):

1. **Repository Boundary**: This repository is dedicated to `chatgpt-codex-plugin-autopilot`. The material in `plugins/no-ai-slop/` represents an unbundled reference documentation stub, excluded from the primary release surface.
2. **Disambiguated Identifiers**: Any standalone package distribution or future independent release must use a disambiguated canonical identifier (such as `slop-curator` or a namespaced package slug) to prevent account catalog collisions.
3. **Upstream Directory Coordination**: Users encountering duplicate catalog entries in Codex or ChatGPT desktop clients should coordinate with OpenAI directory support and avoid name-only uninstalls across conflicting package IDs.
